# OnlyTrusted — Offline Threat Intel: scam PATTERNS v2
#
# Prefix-match ruleset. The scanner tries each pattern against normalised
# E.164 phone numbers (digits only, leading +) using startsWith semantics.
# Comments start with '#'; blank lines ignored.
#
# Format per line:
#   <prefix>  <severity>  <label>
#
#   <prefix>    required — digits with leading '+' (e.g. +1876)
#   <severity>  required — one of: critical | high | medium
#   <label>     required — short human-readable reason (no commas)
#
# Severity meaning:
#   critical  always a scam / premium-rate trap in >95% of calls to US targets
#   high      documented scam-heavy range; most legitimate users won't call it
#   medium    frequently abused but has legitimate users too; show as warning
#
# Sources (all public record, no proprietary data):
#   - FCC Enforcement Bureau robocall citations (fcc.gov/robocalls)
#   - FTC Consumer Sentinel Network data book (ftc.gov/sentinel)
#   - FCC Call Blocking rules (47 CFR § 64.1200)
#   - UK Ofcom enforcement notices (ofcom.org.uk)
#   - CRTC enforcement advisories (crtc.gc.ca)
#   - BBB Scam Tracker trend reports (bbb.org/scamtracker)
#   - Public FCC filings on "one-ring" cousin scams (Caribbean +1-xxx)
#
# Review cadence: this file is a snapshot. Patterns change as scammers rotate
# ranges. Refresh quarterly or when FCC publishes new enforcement actions.
#
# Last updated: 2026-10-30 (v2 — removed whole-country patterns, see note below)

# NOTE on whole-country patterns:
# Previous versions of this file included broad patterns like "+91" (India),
# "+92" (Pakistan), "+234" (Nigeria), etc. flagging any call from those
# countries as a tech-support / 419 scam origin. We removed them in v2
# because they generate massive false-positive storms for anyone whose
# address book is in that country (e.g. 1,400+ Indian contacts getting
# flagged just because +91 is their country code). The honest truth is
# that FTC statistics describe where scam calls TO US targets originate —
# they say nothing about calls between Indian friends or family. We now
# only match SPECIFIC area / exchange / premium-rate ranges that are
# documented scam-heavy regardless of the recipient's home country, and
# the scanner additionally skips any pattern that matches the user's own
# home country code to avoid flagging the user's local contacts.
